## 1. Possible XSS in the spreadsheet preview

`apps/web/components/chat/attachment-preview.tsx:343` injects HTML generated by `xlsx-preview` from an uploaded `.xlsx` via `dangerouslySetInnerHTML`, with no sanitizing.

- Whether it's exploitable depends on whether `xlsx-preview` escapes cell text. If it doesn't, a cell containing `<img src=x onerror=...>` runs script in the viewer's session.
- **This matters more now:** in the desktop app, pages can call the Tauri shell's commands, so a script injected here could also open windows.
- **Fix:** run each sheet's HTML through DOMPurify before rendering. That settles it regardless of how the library behaves.
